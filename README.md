# 🕌 NurMuslim - Superapp Islami Indonesia

**NurMuslim** adalah aplikasi Islami serba ada yang dirancang khusus untuk memenuhi kebutuhan ibadah harian umat Muslim di Indonesia secara modern, cepat, dan terintegrasi.

---

## 📱 Download Aplikasi Android (APK)

Aplikasi Android (APK) kini secara otomatis di-build dan dipublikasikan di **GitHub Releases**.

👉 **[Download APK Terbaru (v1.0.0)](https://github.com/bang-gantenk/nurmuslim-superapp-islamic/releases/tag/v1.0.0-apk)**
👉 **[Lihat Semua Rilis APK di GitHub](https://github.com/bang-gantenk/nurmuslim-superapp-islamic/releases)**

### Cara Install APK di HP Android:
1. Klik link download APK di atas via Smartphone Android Anda.
2. Unduh file `NurMuslim-SuperApp-v1.0.0.apk`.
3. Buka file APK yang sudah diunduh. Jika muncul peringatan *"Install from unknown sources"*, aktifkan izin instalasi untuk peramban/browser Anda.
4. Klik **Install** dan buka aplikasi NurMuslim!

## ✨ Fitur-Fitur Utama

- 🕌 **Jadwal Sholat & Azan Otomatis** — Waktu sholat presisi berdasarkan lokasi dengan notifikasi Azan.
- 🧭 **Kompas Arah Qiblat** — Menentukan arah Kiblat secara cerdas dengan sensor kompas.
- 📖 **Al-Qur'an Digital 30 Juz** — Dilengkapi teks Arab, audio murattal, dan terjemahan Bahasa Indonesia.
- 📻 **Radio Sunnah Stream** — Dengarkan siaran radio dakwah Islami secara live streaming.
- 🧮 **Kalkulator Zakat** — Penghitungan zakat maal & zakat penghasilan secara akurat.
- 🤲 **Kumpulan Doa & Artikel Islami** — Referensi doa harian, zikir, dan artikel keislaman.
- 👥 **Forum Komunitas & Cari Masjid** — Berinteraksi dengan sesama Muslim dan temukan lokasi masjid terdekat.

## 🛠️ Teknologi yang Digunakan

- **Frontend Framework**: React 19 + TypeScript + Vite
- **UI Components & Styling**: Tailwind CSS + Lucide React + Motion
- **Cross-Platform Mobile**: Capacitor (Android APK Build)
- **Offline / PWA**: Vite PWA Plugin + Service Worker
- **CI/CD Build Automation**: GitHub Actions (Otomatis compile APK & deploy ke GitHub Releases & GitHub Pages)

## 🚀 Pengembangan Lokal (Local Development)

```bash
# Clone repository
git clone https://github.com/bang-gantenk/nurmuslim-superapp-islamic.git
cd nurmuslim-superapp-islamic

# Install dependensi
npm install

# Jalankan server pengembangan
npm run dev

# Build aplikasi web
npm run build
```
